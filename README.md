## Overview
This repository contains my **very first Printed Circuit Board (PCB) design project**, built completely from scratch using **KiCad EDA**. 

This project serves as a hands-on milestone to transition into professional hardware engineering and establish an end-to-end Electronic Design Automation (EDA) workflow—spanning schematic capture, footprint assignment, 2-layer PCB layout routing, and design rule verification.

---

## Technical Highlights & Workflow
* **Schematic Design:** Created clean circuit schematics with proper power/ground routing, component value selection, and netlist generation.
* **Component Footprint Assignment:** Mapped symbols to standard surface-mount (SMD) / through-hole (TTH) component footprints.
* **PCB Layout & Routing:**
  * Designed a compact 2-layer PCB layout.
  * Optimized component placement for minimal trace lengths and noise.
  * Added pour areas / ground planes and clear silkscreen text for assembly clarity.
* **Design Rule Check (DRC):** Fully verified layout constraints; passed with **0 DRC errors and 0 warnings**.
* **Version Control:** Managed and tracked hardware source files using Git and GitHub.
